# Thanksgiving

Mobile-friendly trip planner for the Thanksgiving 2026 road trip from Irving, TX to Destin, FL (Nov 25 to 29).

Everything is in a single self-contained page, `index.html`. Open it in a browser, or turn on GitHub Pages for this repo and open the site on your phone.

Features: countdown and a live "Right now" card, an editable day-by-day itinerary with Google Maps directions, a drive plan with driver rotation, a map, weather (live forecast from Open-Meteo, or typical climate when no forecast is available), reservation and packing checklists, and an expense splitter with a settle-up summary. Edits are saved in the browser's local storage.

Tip: add `?now=2026-11-26T14:00:00-06:00` to the URL to preview the in-trip views.
